# Style notes

The user's preferences, learned over time. Claude reads this before every job and adds a line whenever the user says "I prefer…", "always…", "never…". Newest at the bottom. Date each line.

## Defaults (2026-10-13)
- Original by default: no reframing, resize or quality change unless asked.
- Quality never drops to keep a file small. A heavier file is fine.
- Stack hook: line 1 white, line 2 gold `#FFC84D`. Credit "Inspired by <Movie> (<year>)" in grey.
- Emojis go in the post caption, not in the video text.
- Drama Stack: line 1 = title, line 2 = "Part N". No jokes, no emojis.
- Subtitles on finished films (original format): **Sammy's style** = preset "sammy subs" (style `sammy`): bold yellow-orange `#FFE54C`, thick black outline (4.5), lowercase, bottom centre, size 64 at 1080p, max 2 lines. Subtitles go on last, after joining and enlarging; keep a clean copy. (Was "house style" thin off-white until 2026-10-17: that was wrong.)
- On Stack: big white captions under the video.
- Characters near the frame edges (e.g. the Usual Suspects clip): use a wider crop (zoom ≈ 1.2, preset "wide stack").
- Cold open: only when asked.

- 2026-10-14: subtitle style = the yellow-orange bold one ("style 1"), from the Sea Bass / Towel Fight finals.
